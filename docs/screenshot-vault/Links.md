# Links between notes

Wikilinks connect notes in the vault. Open a link to follow it, or inspect incoming links in the backlinks pane.

> [!tip] Follow the thread
> The backlinks pane lists notes that link here. The outgoing links pane lists links from this note.

## Explore this vault

- [[Editor]] shows live preview, source and reading modes.
- [[Graph view]] draws connections between notes.
- [[Search]] finds text across the vault.
- [[Code blocks]] shows a Python block and its output.

Embed a note with `![[Editor]]`.
