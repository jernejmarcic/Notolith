# Obsidian vaults

Notolith opens Obsidian vaults and reads their editor and file preferences, appearance, core plugins, hotkeys, bookmarks, daily notes, templates, graph settings and workspaces.

Theme CSS supplies colours. Font and size preferences come from `appearance.json`; layout follows Notolith's UI.

This vault's `.obsidian` folder sets live preview, an accent colour and text size. Open [[Editor]] or [[Links]] to see them.
