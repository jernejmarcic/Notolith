# Sidebar panes

What to look for: each pane of the right sidebar (Ctrl+Alt+R shows or hides it)
reports on the note that is open. Open this note and compare. Each pane has its
own switch under Settings > Core plugins.

| pane | what this note should give you |
| --- | --- |
| Outline | the headings of this note, in order, click to jump |
| Linked mentions (backlinks) | the notes that link here: [[Feature Tour]] does, so it is listed |
| Unlinked mentions | notes that write "Sidebar panes" without a link, under the backlinks (a search of the vault, off by default; see [[Mentions Without Links]]) |
| Outgoing links | every link in this note, and unresolved ones listed apart |
| Tags | every tag in the vault with counts, click to search; the button sorts by count or name; see [[Tags]] |
| Properties | every property in the vault; see [[Properties]] |
| Footnotes | this note's footnotes[^1], click to jump |
| Search | the vault search box, Ctrl+Shift+F; see [[Search Operators]] |
| Bookmarks | see [[Navigation]] |
| Local graph | the branch icon in the sidebar tabs; see [[Graph View]] |

The status bar at the bottom shows the backlink count, the property count,
the editing mode icon, and words and characters (Core plugins > Word count).
Select some text and the bar shows the selection's counts instead.

With Pop-out windows on (see [[Pop-out Windows]]), right-click a sidebar tab and
use "Detach pane" or "Detach sidebar" to move it into a window of its own.

[^1]: Footnotes are listed in the Footnotes pane (Core plugins > Footnotes view), and drawn as numbers in live preview.
