# Export to PDF

What to look for: "Export to PDF" (`workspace:export-pdf`, in the palette) turns
the open note into a PDF file, drawn on white paper in the light theme.

## Try

1. Open [[Callouts]] or [[Maths]], run "Export to PDF".
2. A dialog offers Page size (A3, A4, A5, Legal, Letter, Tabloid), Orientation
   (Portrait or Landscape), Margin (None, Default, Small), Downscale, and
   "Include file name as title".
3. Confirm, choose where to save (it starts beside the note), and open the result. Callouts, maths, tables
   and code keep their drawing.

This is for one note. For the whole vault as a website see [[Publish]].
