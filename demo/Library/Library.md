# Library

A small collection of 12 book notes under `Books/`, each carrying `author`,
`category`, `pages`, `price`, `rating` and `status` properties, queried by
[[Base Blocks]] and by `Library.base` (open it directly as a tab - it sits
next to this note, in `Library/Library.base`) with several views: a table
ordered by name/status/formula, grouped and sorted views, and a card view.
