# Newer features

What to look for: a map of the notes that cover features added after the
first demo vault. Every note says what a correct render or behaviour looks
like. Several features here are off by default or need an outside tool; the
note for each says which setting turns it on.

## Diagrams

- [[Mermaid]] - flowchart, sequence, class, state, ER, Gantt and pie, and the
  two error states. Needs `mmdr`.
- [[PlantUML]] - `plantuml` and `puml` fences, with and without `@startuml`.
  Needs `plantuml` and Java.
- [[TikZ]] - TikZJax's block, a bare `tikzpicture`, pgfplots and what is
  refused. Needs `latex` and `dvisvgm`.
- [[Graphviz]] - `dot` and `graphviz` fences. Needs `dot`.
