# Feature tour

What to look for: one line per feature the app supports, each linked to the note
that shows it and says how to try it. The core plugin ids are the ones in
Settings > Core plugins; a few are off in this vault's `core-plugins.json`
(footnotes, slash commands, random note, unique note, slides, audio recorder,
publish) and a few are off by default (community plugins, slash commands, image
annotation), so if a command is missing, switch the plugin on there. Things
that need a second machine, a server or a build step are marked as such in their
notes. For the older map see [[Welcome]] and [[Newer Features]].
